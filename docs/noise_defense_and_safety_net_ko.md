# 🛡️ 실시간 노이즈 방어 및 6대 안전망 설계서 (Noise Defense & Safety Nets)

문서 버전: v2.1 | 최종 수정일: 2026-08-26

## 1. 개요 (Overview)

포켓몬 챔피언스는 60FPS 속도로 카메라가 역동적으로 회전하고, 스킬 불꽃, 폭발 파티클, 화면 전환 컷신이 쉴 새 없이 발생합니다.
본 문서는 이러한 극한의 동적 게임 환경에서 **가짜 피격 진동 오작동률을 0%로 완벽 차단**하는 **6중 실시간 노이즈 방어 체계**의 설계 원리와 구현 방식을 상세히 기술합니다.

## 2. 6중 실시간 안전망 구조도 (6-Layer Safety Architecture)

```
[ 60FPS 실시간 비디오 프레임 ]
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 1계층: 3중 적응형 전처리 (CLAHE / Pure White Mask / Otsu)            │
│  - 배경 경기장 조명, 네온사인, 화려한 스킬 이펙트 광원 100% 제거       │
└────────────────────────────────────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 2계층: 타이머(MM:SS) 정규식 사전 블랙리스트                          │
│  - 배틀 남은 시간(04:58), 매칭 대기 타이머, 시계 기호(⏱, ⏰) 사전 차단 │
└────────────────────────────────────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 3계층: 물리적 체력 상/하한선 검증 (Sanity Bounds)                    │
│  - 40 <= Max HP <= 750, 0 <= Current HP <= Max HP 규칙 엄격 적용        │
└────────────────────────────────────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 4계층: 2프레임 연속 일치 합의 락 (2-Frame Consensus Lock)           │
│  - 최근 1.5초 윈도우 내 '동일 수치가 2회 연속 안착' 시에만 데미지 확정   │
│  - 1프레임 찰나의 파티클 스침/오독(115/150 -> 15/150) 100% 무시        │
└────────────────────────────────────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 5계층: 8.0초 연출 자동 동결 (Cutscene Hold & Freeze)                │
│  - 스킬 컷신/카메라 회전 시 ΔHP=0 계산 동결 (가짜 기절 진동 차단)       │
│  - 빨간 체력(<=20%) 진동 루프는 연출 중에도 8.0초간 매끄럽게 유지       │
└────────────────────────────────────────────────────────────────────────┘
              │
              ▼
┌────────────────────────────────────────────────────────────────────────┐
│ 🛡️ 6계층: 포켓몬 교체(0.8s 뮤트) 및 기절(HP=0) 전용 분기              │
│  - Max HP 변경 시 교체 감지 ➔ 0.8초간 피격 뮤트 & 새 기준 자동 갱신   │
│  - Current HP = 0 시 즉각 기절 확정 & 빨피 진동 루프 영구 정지          │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. 핵심 안전망 세부 메커니즘

### 3.1 2프레임 연속 일치 합의 락 (Consensus Lock)
단일 프레임 OCR 결과에 즉시 반응하면, 스킬 파티클이 글자를 스치는 1프레임 동안 체력이 잘못 읽혀 원치 않는 강타 진동이 발생할 수 있습니다.
따라서 **최근 1.5초 슬라이딩 윈도우에서 가장 빈번하게 등장한 최빈값(`mode_curr`)이 최근 2프레임 연속으로 동일할 때만 정적 안착으로 인정**합니다.

```python
# 1.5초 슬라이딩 윈도우 히스토리
currs = [item[1] for item in self._ocr_history]
counts = Counter(currs)
mode_curr, mode_count = counts.most_common(1)[0]

# 최근 연속 2프레임이 동일한 최빈값일 때만 최종 확정
last_two = currs[-2:]
is_steady = (last_two[0] == mode_curr and last_two[1] == mode_curr)
```

### 3.2 8.0초 연출 자동 동결 (Cutscene Hold)
다이맥스, Z기술, 강력한 특수기 연출 중에는 카메라가 상대 진영으로 회전하며 아군 체력 숫자가 화면에서 일시적으로 사라집니다.
* **일반 상태**: 숫자가 안 보이면 `battle_state = "CUTSCENE"`으로 자동 전환하여 $\Delta\text{HP} = 0$으로 동결, 체력이 0이 된 것으로 오판해 울리는 가짜 기절 진동을 원천 차단합니다.
* **빨간 체력 상태 (<=20%)**: 긴 기술 연출(4~7초) 중에도 진동이 끊기지 않도록 `last_number_seen_time` 타임아웃을 **8.0초**로 확장하여, 컷신이 끝날 때까지 심장박동 펄스와 베이스 루프를 안정적으로 유지합니다.

---

### 3.3 포켓몬 교체(Switch) vs 피격(Damage) 완벽 분리
포켓몬이 교체되면 최대 체력 자체가 달라집니다 (예: 팬텀 140 -> 한카리아스 183).
이를 단순 수치 차이로 계산하면 $-43$ 피격 또는 회복으로 오작동합니다.
* 시스템은 `max_hp != confirmed_max_hp`를 즉시 감지하여 **"교체 이벤트"**로 전환합니다.
* 교체 직후 **0.8초 동안 피격 진동 계산을 자동 뮤트**하고 새로운 포켓몬의 기준 체력으로 안전하게 재정합합니다.
