# 📋 제품 요구사항 정의서 (PRD & System Specifications)

문서 버전: v2.1 | 최종 수정일: 2026-08-26

## 1. 프로젝트 목적 (Project Objective)
닌텐도 스위치 『포켓몬 챔피언스 (PokéChamps)』 대전 중 발생하는 아군 포켓몬의 피격 상황을 실시간으로 감지하여, bHaptics TactSuit 전신 햅틱 슈트로 생생한 충격 및 심장박동 진동을 전달함으로써 궁극의 배틀 몰입감을 제공합니다.

---

## 2. 요구사항 명세 (Functional Requirements)

### 2.1 비디오 캡처 및 화면 인식 (Vision & Recognition)
- [x] **FR-V01**: HDMI 캡처보드 및 OBS 가상 카메라 1080p@60FPS 무지연 입력 지원.
- [x] **FR-V02**: 원클릭 아군 체력바 자동 스냅 (Auto-Snap ROI, 0.1픽셀 단위 정밀도).
- [x] **FR-V03**: 3중 적응형 전처리(CLAHE, Pure White Mask, Otsu) 기반 0.1초 고속 RapidOCR.
- [x] **FR-V04**: 경기 타이머(04:58) 및 시계 기호(⏱) 오인식 100% 원천 차단.

### 2.2 데미지 산출 및 안전망 (Damage & Safety)
- [x] **FR-D01**: 2프레임 연속 일치 합의 락 (Consensus Lock)으로 1프레임 노이즈 방어.
- [x] **FR-D02**: 스킬 컷신 및 카메라 회전 시 가짜 피격 0% 차단 (Cutscene Hold).
- [x] **FR-D03**: 포켓몬 기절(`0/max_hp`) 시 즉각 기절 확정 및 빨간 체력 진동 루프 종료.
- [x] **FR-D04**: 포켓몬 교체(`Max HP` 변동) 감지 시 0.8초간 피격 뮤트 및 기준값 재설정.

### 2.3 햅틱 피드백 및 모터 제어 (Haptics)
- [x] **FR-H01**: 4단계 데미지 비례 피격 피드백 (경타, 중타, 강타, 치명타).
- [x] **FR-H02**: 피격 옵션별 독립 신체 부위(정면만, 후면만, 정+후 전체) 선택 기능.
- [x] **FR-H03**: 잔여 체력 20% 이하 시 심장박동 펄스(0.85s) 및 베이스 상시 루프 진동 발송.
- [x] **FR-H04**: 긴 기술 연출 중에도 8.0초간 끊김 없이 빨간 체력 진동 지속 유지.
- [x] **FR-H05**: bHaptics TactSuit X40 (40점) 및 TactSuit X16 (16점) 자동 다운샘플링 지원.

### 2.4 사용자 인터페이스 (GUI & UX)
- [x] **FR-U01**: PySide6 기반 모듈형 QDockWidget 도킹 UI 시스템 (분리/이동/탭/원클릭 복원).
- [x] **FR-U02**: F11 전체 화면 토글 (Full Screen) 및 Esc 복원.
- [x] **FR-U03**: 실시간 2D 모터 뷰어 및 네온 감쇄 애니메이션.
- [x] **FR-U04**: 독립 투명 Always-on-Top 플로팅 HUD 지원.
- [x] **FR-U05**: 이벤트 로그 폰트 크기 조절 슬라이더 (8pt ~ 22pt).
