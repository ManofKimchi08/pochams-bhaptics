# 🏗️ 시스템 아키텍처 및 멀티스레딩 모델 (System Architecture & Threading)

문서 버전: v2.1 | 최종 수정일: 2026-08-26

## 1. 개요 (Overview)

본 문서는 영상 캡처 지연 시간($\le 30\text{ms}$), 햅틱 전송 지연 시간($\le 20\text{ms}$)을 달성하기 위한 **60FPS 비동기 멀티스레딩 파이프라인 및 상태 머신(State Machine)**의 소프트웨어 아키텍처 설계서입니다.

---

## 2. 3계층 멀티스레드 아키텍처 (3-Tier Threading Model)

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 📺 계층 1: 60FPS 영상 수신 & 고속 프리프로세서 (Capture Thread)                           │
│  - OpenCV DirectShow / MSMF 기반 1080p@60FPS 실시간 비디오 캡처                         │
│  - ROI 자동 정렬, HUD 렌더링, 0.1초 단위 텍스트 서브영역 큐잉                          │
└───────────────────────────────────────────┬────────────────────────────────────────────┘
                                            │ (OCR Queue: 크롭 이미지 전달)
                                            ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 🔍 계층 2: 3중 적응형 RapidOCR 워커 (OCR Worker Thread)                                │
│  - 3.0x 바이큐빅 확대 + Unsharp Mask + CLAHE / White Mask / Otsu 3단 파이프라인          │
│  - 2프레임 연속 합의 락 (Consensus Lock) 판정                                          │
└───────────────────────────────────────────┬────────────────────────────────────────────┘
                                            │ (Damage Event: 감소율 % 전달)
                                            ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 🎽 계층 3: 햅틱 제어 및 bHaptics SDK 디스패처 (Haptic Worker Thread)                    │
│  - 피격 등급 분류 및 부위별(정면/후면/전체) 모터 매트릭스 계산                          │
│  - bHaptics 공식 C++ SDK(bhaptics_python) 비동기 전송                                  │
│  - 백그라운드 빨간 체력(<=20%) 심장박동 / 상시 루프 관리                                │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. 유한 상태 머신 (Finite State Machine)

```
                 [ IDLE / WAITING ]
                         │ (체력 숫자 최초 감지)
                         ▼
                  [ IN_BATTLE ] ─── (체력 <= 20%) ───▶ [ RED_HP_ACTIVE ]
                         │                                    │
                         ├─────── (숫자 미인식 > 1.3s) ──────┤
                         ▼                                    ▼
                 [ CUTSCENE_HOLD ]                     [ RED_HP_HOLD ]
                 (데미지 계산 동결)                     (8.0s 동안 루프 유지)
                         │                                    │
                         ├─────── (Current HP = 0) ───────────┤
                         ▼                                    ▼
                                  [ FAINTED (기절) ]
                                  (즉시 루프 영구 종료)
```

## 4. 스레드 동기화 및 락(Lock) 안전성
* **UI-Engine 비동기 큐**: 모든 비전 연산과 햅틱 통신은 Qt 메인 GUI 스레드를 블로킹하지 않도록 `queue.Queue`와 백그라운드 데몬 스레드로 격리됩니다.
* **스레드 세이프 상태 동기화**: `threading.Lock`을 통해 실시간 2D 모터 시각화 뷰어와 bHaptics 디스패처 간의 모터 배열 읽기/쓰기 충돌을 방지합니다.
